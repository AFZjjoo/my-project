# Gemini Image Generator

A simple Python project that simulates an AI image generator using Object-Oriented Programming (OOP).

## Project Description

This project demonstrates the basic concepts of Object-Oriented Programming by simulating how Google's Gemini image generation system works. The program receives a text prompt from the user and returns a generated image message.

Although this project does not connect to the real Gemini API, it is designed to demonstrate software design concepts in a simple and educational way.

---

## Features

* Object-Oriented Programming (OOP)
* Singleton Design Pattern
* Inheritance
* Method Overriding
* Exception Handling
* Unit Testing using `pytest`
* Simple and easy-to-understand code

## Installation

Clone the repository:

```bash
git clone https://github.com/AFZjjoo/my-project.git
```

Move into the project folder:

```bash
cd my-project
```

Install the required packages:

```bash
pip install -r requirements.txt
```

---

## Running the Project

Execute the program:

```bash
python main.py
```

Example:

```
===== Gemini Image Generator =====
Enter your image prompt: Cat

Result:
Image 'Cat' has been successfully generated by Gemini.
```

---

## Running the Test

Run the unit test using pytest:

```bash
pytest
```
